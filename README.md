# Calle Macarena nº16 · Descarga del modelo y los renders

[**Descargar todos los archivos en un ZIP**](https://github.com/juanmaesp8-svg/Calle-Macarena/archive/refs/heads/codex/descarga-galeria-renders.zip)

El ZIP incluye el modelo editable, la exportación GLB, los diez renders originales, las galerías, el informe de control y los archivos necesarios para reproducir el trabajo.

1. Descarga y extrae el ZIP completo.
2. Dentro de la carpeta extraída, abre `entrega/galeria.html` con tu navegador para ver y ampliar las diez imágenes sin conexión.
3. Conserva la estructura de carpetas, especialmente `entrega/`, `renders/` y `control/`, para que funcionen los enlaces. El archivo `.blend` se abre con Blender.
