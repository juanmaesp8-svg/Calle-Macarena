Descargar todo: [ZIP de esta revisión](https://github.com/juanmaesp8-svg/Calle-Macarena/archive/refs/heads/codex/modelo-v2-trastero.zip). Extraer el ZIP y abrir el `.blend` con Blender 4.3.2 o compatible; importar el `.glb` con File→Import→glTF.

189 comprobaciones geométricas superadas. Los datos sin cota y discrepancias quedan documentados. El `.blend` incluye shaders y microfibras; el GLB facilita inspeccionar geometría y conserva materiales simplificados. Los fondos de calles son contexto gráfico; no se han añadido dimensiones de parcelas vecinas.

Esta revisión contiene una primera vista Cycles nueva. Las diez imágenes anteriores corresponden a V1 y se conservan en la rama `codex/descarga-galeria-renders`. Los EXR limpios se incluyen; buffers de cálculo, dependencias instaladas y binarios OIDN se regeneran según el manual.
